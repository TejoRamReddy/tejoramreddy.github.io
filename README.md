# K. Tejo Ram Reddy — Portfolio

This portfolio includes the profile photo and all required website files.

## Files
- `index.html` — portfolio page
- `style.css` — styling
- `script.js` — interactions
- `profile.png` — profile photo

## Run locally
Keep all four files in the same folder and double-click `index.html`.

The image is already configured as:
`src="profile.png"`

No image-path changes are required.
